# vertex-learning-platform

Vertex is an AI-powered learning platform with intelligent content search and courses. Built with Next.js (App Router), Tailwind CSS, Clerk authentication, Sanity Studio, and the Sanity Context MCP.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Design System

Visit [http://localhost:3000/design-system](http://localhost:3000/design-system) to view the Vertex design system showcase, tokens, typography scale, buttons, inputs, badges, and card components.
